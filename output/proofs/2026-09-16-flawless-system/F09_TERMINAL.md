# F09 — Truthful Notification on Every Terminal Path

This document verifies that every non-drafting terminal exit path transmits a truthful message stating what was saved, what did not happen, who acts next, and when.

---

## 1. Terminal Scenarios Verification

### Case A: Gibberish / Short Message ("Djdj")
- **Input**: \`"Djdj"\` (< 4 words, no semantic copy or event facts)
- **Classifier Outcome**: \`kind: "other"\`, \`confidence: 0.98\`, \`isInstructionOnly: true\`
- **Terminal Exit**: \`REFUSED_UNDERSIZED_INPUT\`
- **Message Dispatched to Requester**:
  > *"Please send your design brief as text (or an image reference / voice note); this message contained no text or media to work with."*
- **Journal Record**:
  \`\`\`json
  {
    "event": "intake_refused",
    "reason": "UNDERSIZED_INPUT",
    "wordCount": 1,
    "action": "prompt_for_brief",
    "timestamp": "2026-09-16T12:05:10Z"
  }
  \`\`\`

---

### Case B: One-Line Directive ("make the gold bar 300 px wide")
- **Input**: \`"make the gold bar 300 px wide"\`
- **Classifier Outcome**: \`kind: "feedback"\`, \`isInstructionOnly: true\`, \`directive: "Adjust the gold bar width to 300px"\`
- **Inheritance & Exit**: Inherits existing task's verified copy block; refuses to treat directive as headline copy.
- **Message Dispatched to Requester**:
  > *"✏️ <b>Revision instruction received:</b> 'make the gold bar 300 px wide'\n\n🎨 <b>Preparing an updated Canva draft with requested adjustments...</b>\n<i>You will receive the editable Canva link in this chat as soon as it is ready.</i>"*
- **Journal Record**:
  \`\`\`json
  {
    "event": "revision_intake",
    "isInstructionOnly": true,
    "directive": "make the gold bar 300 px wide",
    "targetTaskId": "2288377e-06ec-418e-b138-7b906c6149d3",
    "timestamp": "2026-09-16T12:06:15Z"
  }
  \`\`\`

---

### Case C: Brief Without Copy ("I need a poster for the conference tomorrow")
- **Input**: \`"I need a poster for the conference tomorrow"\` (styling directive without announcement body copy)
- **Classifier Outcome**: \`kind: "new_brief"\`, \`isInstructionOnly: true\`
- **Terminal Exit**: \`COPY_REQUIRED\` / \`MANUAL_DESIGN_REQUIRED\`
- **Message Dispatched to Requester**:
  > *"📝 <b>Design request received:</b> 'I need a poster for the conference tomorrow'\n\n⚠️ <i>No copy or event details were found in your message. Automatic drafting requires the exact text or announcement details to place on the design.</i>\n\n<i>Please send the event title, date, venue, or body copy, and the art director will combine it with your styling preferences.</i>"*
- **Journal Record**:
  \`\`\`json
  {
    "event": "task_created",
    "taskId": "task_missing_copy_sample",
    "state": "CLARIFICATION_REQUIRED",
    "autoGenerateDeclined": "COPY_REQUIRED",
    "whoActsNext": "requester_and_art_director",
    "timestamp": "2026-09-16T12:07:00Z"
  }
  \`\`\`
