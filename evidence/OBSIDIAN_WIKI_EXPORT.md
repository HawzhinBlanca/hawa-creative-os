# Hawa Creative OS

Repo note: [[Hawdesign]] · Area: [[Creative AI & Kurdish Advertising]] · Architecture: [[architecture-map]]

## Overview

Hawa Creative OS (`/Users/hawzhin/Hawdesign`) is an autonomous, high-assurance advertising design studio operating system engineered specifically for Iraqi Kurdistan and Middle Eastern commercial markets. It ingests advertising requests from office channels (Telegram, WhatsApp, email), synthesizes exact briefs, generates live-editable `.hyc` documents with Kurdish Sorani typography, enforces deterministic pre-publication QA checks, presents canonical approval workflows in the Hawa Desk PWA, and idempotently publishes deliverables to Google Shared Drive and Google Sheets.

## Architectural Invariants (Master Spec)

1. **Desk is Canonical**: The Hawa Desk PWA (`apps/desk`) is the authoritative source for intake, brief editing, candidate rule reviews, and final approvals. Chat adapters (Telegram, WAHA) act purely as non-authoritative message ingress.
2. **Editable Design Artifacts (`.hyc`)**: HyCanvas source documents are the canonical asset. No flattened bitmaps with baked-in text are ever emitted as final deliverables; text remains live and addressable.
3. **Reference Pixels Never Ship**: Art-direction reference images generated by visual models have `shippedInArtifact: false` enforced at schema level.
4. **Pre-Retrieval Scope Locking**: Client scope is locked in PostgreSQL before similarity search commences. Cross-tenant leakage is physically impossible.
5. **Exact Fact & Copy Preservation**: Every claim, price (`IQD`, `د.ع`), phone number (`0750...`), and discount in generated copy traces back to an approved source.
6. **Deterministic QA Supremacy**: Hard deterministic checks (dimensions, exact copy, protected tokens, font glyphs, brand logo hashes, safe zones, WCAG contrast) strictly outrank probabilistic visual models. The visual judge cannot override hard failures.
7. **Two-Cycle Autonomous Repair Ceiling**: The repair state machine allows a maximum of 2 autonomous repair cycles before escalating to `OPERATOR_REQUIRED`.
8. **UAX #9 First-Strong Directional Isolation**: All Kurdish Sorani and Arabic text blocks are isolated with Unicode Directional Isolates (`U+2067` / `U+2069`) to guarantee layout stability across mixed numbers, Latin currencies, and punctuation.
9. **Zero Secret Leakage**: AST and static pattern scanners verify zero credentials or API keys in the codebase.
10. **Outbox Idempotency**: Transactional outbox pattern guarantees single-delivery semantics across external side effects even under 40% network drop chaos.

## Monorepo Package Structure

- `apps/desk`: React 19 + TypeScript + Vite canonical office operations desk PWA (7 operational views).
- `apps/core`: Hono-based REST API with RFC 7807 problem details, OWASP security headers, and asset sanitization.
- `apps/worker`: Restate durable execution workflows for background pipeline orchestration.
- `packages/contracts`: Pure TypeScript domain contracts, schemas, and result types.
- `packages/domain`: Pure domain logic: state machine, Kurdish Sorani orthography, protected tokens, client DNA, asset sanitizer.
- `packages/qa`: Deterministic QA engine: RTL bidi validator, WCAG 2.2 contrast calculator, safe-zone layout bounds.
- `packages/creative`: Brief builder, design router, creative director, multi-format variant reflow, semantic `.hyc` diff.
- `packages/integrations`: Normalized message adapters (Telegram, WAHA) and publishers (Google Shared Drive, Google Sheets).
- `packages/retrieval`: Pre-retrieval client-scoped vector search and asset catalog indexing.
- `packages/db`: PostgreSQL 17 schema parser, migration runner, and table/RLS consistency checker.
- `packages/observability`: Distributed tracing, correlation ID middleware, OpenTelemetry exporters.
- `packages/evals`: Model tournament runner, retrieval precision evaluator, copy guard, visual rubric, adversarial safety benchmark.
- `packages/testkit`: In-memory fault injection, chaos simulators, fake adapters, concurrency stress matrix.
