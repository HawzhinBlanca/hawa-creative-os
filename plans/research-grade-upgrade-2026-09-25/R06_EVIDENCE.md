# R06 — Offline visual-judge calibration boundary

**Date:** 2026-09-25. **Source:** `bf7653f`. **Status:** in progress. No real judge comparison or model-promotion result is claimed.

`packages/evals/src/judge-calibration.ts` adds an offline comparison packet for exact, decoded, hash-pinned, equally sized PNG exports. It refuses image metadata that could reveal an arm. Its generic rubric receives the brief and two images without composite or ranking scores, permits A/B/tie/abstain, and states that the result is advisory. The response parser bounds the reason, validates dimension/severity and nonempty normalized evidence regions, and rejects extra fields. A region and explanation are **claims**, not proof that the pixels contain the alleged defect.

The analyzer requires both image orders to name the same bytes in reverse, a pinned prompt version, distinct packet hashes and the same model. It requires distinct identified human voters and records whether at least three valid votes yield a majority. It reports order disagreement, abstention, human consensus agreement, seeded-defect detection, clean-control false critical findings, and known or missing cost and latency. Counts are broken down by language, format and seeded-defect severity. Correlated cases are explicitly counted as cases, not independent lineages. The report always says `offline_diagnostic_only` and `admissionQualified: false`; it cannot override deterministic hard QA or choose a production model.

The synthetic tests cover corrupt/mismatched PNGs, arm-revealing metadata, unequal dimensions, tie and abstain responses, invalid evidence regions, changed order/model bindings, duplicate cases and judges, one detected seeded defect, a false critical finding on a clean control, subgroup counts and unknown receipts. Focused **1 file / 3 tests**, package build and typecheck, and full workspace typecheck passed. The fixed source suite passed **419 files / 3,125 tests**, with **4 files / 48 tests skipped**. The repository security commit hook reported zero secrets.

This is diagnostic plumbing only. The analyzer does not inspect the image bytes from its observation record; a caller must verify each hash against the sealed image package and the prompt packet before analysis. It does not authenticate human identities, validate visual truth of a finding, calculate lineage-clustered uncertainty or establish a preregistered superiority/non-inferiority decision. No current Canva-export corpus, independent human labels, authorized independent-family judge calls, provider receipts, metrics-only baseline, cost comparison, or live shadow/canary/rollback evidence was supplied.
