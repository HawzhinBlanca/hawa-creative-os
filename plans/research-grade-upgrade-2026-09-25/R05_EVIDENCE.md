# R05 — Blind comparison package boundary

**Date:** 2026-09-25. **Status:** in progress. No current Canva-export, multi-client human study has been run.

The existing `packageBlindPairs` accepted a nonexistent image path by substituting an empty buffer, then wrote that buffer as a `.png`. It could also overwrite an existing randomization key and rating sheet. The packager now validates all pairs before writing: it requires both files, distinct nonempty bytes, unique brief IDs, and a fresh key/sheet destination. Its image and private key files are created without overwrite with owner-only permissions. A missing second export is refused before the pair directory is created; an attempted second package in the same destination is refused.

The focused design-studio evaluation file passed **13 tests** after this change, including both negative controls, and the package TypeScript build passed. This only hardens a legacy packaging helper. It does **not** verify PNG decodability, Canva export origin, exact source/QC/deployment hashes, arm parity, three-rater blindness, signed corpus permissions, raw vote capture or brief-clustered confidence intervals. It is not a product-admission path.

## Current-export packaging harness

`scripts/package_current_export_study.ts` now provides a separate path for the actual study. A private config names the R04 machine-sealed corpus, an explicit independent review record, a study-specific preregistration, at least three opaque judge IDs, and exactly one current/candidate pair for **every** final-holdout case. Each arm needs the actual PNG, its final-export proof, the archived editable source artifact, QC report and inspected deployment receipt. The packager hashes every file, decodes the complete PNG, checks declared dimensions, checks source/QC hashes, verifies the receipt's manifest/migration and three image revision labels, rejects reused or identical images, and checks the brief bytes against the corpus. It validates the entire set before writing.

The package requires a study-specific preregistration bound to the corpus hash, seed hash, exact holdout count, judge count, primary endpoint and frozen lineage-level analysis rule. It writes an owner-only private key and separate rater folders with opaque pair IDs, identical brief text, A/B PNGs and blank rating forms. Each judge has 50/50 candidate-side balance on a 100-case holdout; arm identity, source hashes and the split seed stay outside the rater folders. The rater PNGs have text/camera metadata removed and any ICC profile name neutralized without changing pixel data or color profile payload; their hashes are checked at analysis time. Original final PNG, source, QC, export proof and deployment receipt bytes are archived in the private bundle with the corpus, review and preregistration. A new directory is required and assembled before being renamed into place. The output status is `packaged_pending_human_ratings`.

`scripts/analyze_current_export_study.ts` verifies the private key seal and every rater image/brief hash, parses quoted CSV ratings, keeps ties, cannot-judge and missing votes in the denominator, and computes a reproducible 10,000-draw interval from **lineage clusters** rather than treating three votes or sibling formats as independent briefs. It prints subgroup counts/means and writes a content-addressed private analysis file. An incomplete sheet cannot meet the superiority criterion. Even a numerical win is `ANALYSIS_PENDING_INDEPENDENT_VERIFICATION`, with `admissionQualified: false` until human identity, artifact and hard-safety review.

One end-to-end synthetic 200-case/100-holdout test passed with three judge folders and 300 key entries. It also refused a missing rights review, changed preregistered case count, changed source bytes, a self-consistent receipt with a forged image revision label, changed PNG bytes and altered rater image bytes. The original synthetic PNG carried candidate-arm text and ICC profile name chunks; the rater copies did not. Blank sheets yielded `INCOMPLETE`; a filled synthetic three-judge sheet reproduced a point estimate of 1.0 while keeping `admissionQualified: false`. Two focused analysis tests verify deterministic clustered results, ties, missing/cannot-judge votes and duplicate-row refusal. After the final metadata check, the R04/R05 focused group passed **4 files / 19 tests** and both package and script TypeScript checks passed.

These tests use synthetic evidence and do not prove that any real Canva export, permission sign-off, independent judge or design-quality result exists. The offline review record identifies an approver but is not a cryptographic identity proof; production study execution needs that human check. R05 remains open until current exports and blinded human judgments are collected under this frozen protocol, with native-language review and current-candidate hard QA.
