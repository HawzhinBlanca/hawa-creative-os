# MVP Readiness Checklist

## Phase 0

- [ ] HyCanvas binary/source checksums recorded.
- [ ] All critical editable/RTL/export/round-trip tests pass or fallback selected.
- [ ] Restate restart/approval-wait proof passes.
- [ ] Seed routing/brief/retrieval/model tournament completed.
- [ ] Architecture ADRs signed.

## Core

- [ ] Hawa Desk is usable without Telegram/WhatsApp.
- [ ] Google OIDC and role authorization pass.
- [ ] PostgreSQL schema, RLS, audit, inbox/outbox pass.
- [ ] One direct task and one Telegram task survive duplicate/restart tests.
- [ ] Ambiguous client performs no retrieval/generation before human choice.

## Client DNA

- [ ] Three pilot clients have approved DNA, assets, fonts, glossary, folders, and review policy.
- [ ] Curated Drive ingestion and source versioning pass.
- [ ] Cross-client and negative-example retrieval tests pass.

## Creative production

- [ ] At least three routine editable templates per pilot client.
- [ ] One novel private-reference/reconstruction route passes.
- [ ] Every final output has `.hyc`, neutral manifest, assets, preview, and QA report.
- [ ] Two automatic repairs maximum and human route work.
- [ ] 40 synthetic + 20 real Sorani cases pass.

## Review/publication

- [ ] Approval binds immutable revision/QC hash.
- [ ] Direct edit invalidates approval and reruns QA.
- [ ] Drive upload/verification and Sheet upsert/reconciliation pass fault tests.
- [ ] Final link returns to source conversation without making chat authoritative.

## Operations

- [ ] Phoenix/OTel traces cover every boundary.
- [ ] Safe error action exists for every failure state.
- [ ] ComfyUI/WAHA isolation and kill switches verified.
- [ ] Clean-host restore succeeds within target.
- [ ] Office operator completes daily workflows using runbooks without developer intervention.

## Pilot exit

- [ ] 100 real tasks completed across three clients.
- [ ] Zero critical security, exact-copy, logo, dimension, RTL, editability, or approval escapes.
- [ ] ≥95% workflow completion without technical rescue.
- [ ] Remaining risks explicitly accepted by office leadership.
