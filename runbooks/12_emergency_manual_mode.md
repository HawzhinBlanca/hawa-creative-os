# Runbook: Emergency Manual Production Mode

Use when AI, workflow, or studio automation is degraded but urgent office work must continue.

1. Create/retain the task in Hawa Desk.
2. Lock client/project and exact brief manually.
3. Open the latest admitted template/source in the editable studio or approved external editor.
4. Designer creates/edits work manually with official assets.
5. Import/checkpoint editable source and neutral manifest.
6. Run available hard QA and native review.
7. record approval against immutable source;
8. publish through the normal publisher when available, or upload manually and enter verified Drive IDs for reconciliation.
9. Record every manual deviation.

Manual mode may bypass model generation, not client isolation, editable source, exact-copy QA, approval, or audit.
