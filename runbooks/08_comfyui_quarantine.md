# Runbook: ComfyUI Node or Workflow Quarantine

1. Disable the workflow/node version in registry and stop new jobs.
2. isolate/rebuild the worker if compromise is possible;
3. preserve job graphs, input/output hashes, logs, model/node manifests;
4. identify every asset generated by the affected versions;
5. determine whether outputs or source packages need regeneration/review;
6. scan source/package and compare against allowlist;
7. restore a known-good immutable worker image/model store;
8. rerun asset golden/security tests before reactivation.

Production UI must never install a replacement community node directly.
